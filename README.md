# 讲座抢报助手（Lecture Enroll Sniper）

一个 Windows 桌面小工具，用于在「报名工具」类讲座报名页面开放名额的**那一秒**自动提交报名表单。

扫码登录 → 自动对时 → 到点按毫秒精度提交 → 失败自动退避重发。多人可同时报名，每人各自一个账号、各自设定发射秒数。

> 仅供个人学习与自用。请遵守报名平台的使用条款与所在学校的相关规定。

---

## 它能做什么

- **提前扫码登录**：活动开放前就把账号登好，不用到点再手忙脚乱
- **毫秒级对时**：不依赖系统时钟，直接量出本机与服务器的时间差
- **按人设定发射秒数**：0.0s / 1.5s / 6.0s，各人错开，避开限流
- **自动补取表单字段**：很多活动开放前拿不到字段，工具会在开放前 5 秒自动补取
- **失败自动重试**：遇到「请求过于频繁」「invalid parameter」会退避后重发
- **可视化日志**：谁在第几秒提交、耗时多少、服务器返回什么，一目了然

## 它做不到什么

- 抢不赢就是抢不赢。名额只有 1 个的时候，延迟差 50ms 也是差
- 平台接口一变就失效。这类工具天然是「跟着平台改」的
- 同一账号有约 2.9 秒的提交频次限制，所以**多个人必须把秒数错开至少 1.2 秒**，否则后一个会被限流挡回去重发

## 快速开始

### 环境

- Windows 10 / 11
- Python 3.10+（需带 tkinter，官方安装包默认自带）

### 安装依赖

```bat
pip install -r requirements.txt
```

### 运行

```bat
python app.py
```

打开后：

1. 把活动链接粘进输入框（或直接点「从剪贴板读取」），工具会识别出活动号
2. 点「添加人员」，填姓名 / 学号 / 学院，双击「秒数」列可改发射秒数
3. 点「开始」，按提示让每个人扫码
4. 扫码完成后工具自动对时并等待开放，到点自动提交

### 打包成 exe

```bat
build.bat
```

产物在 `dist\讲座抢报助手.exe`（单文件，约 38 MB）。

## 工作原理

**1. 扫码登录，拿各自的 token**

每个账号扫码后拿到的 `access_token` 是独立的，提交时按 token 计频次。所以多人报名不是「并发打同一个接口」，而是各打各的。

**2. 对时：不信系统时钟**

本机时钟差个一两秒太常见了。工具的做法是连续请求服务器，观察响应头 `Date` 的**整秒跳变时刻**，用「本机收到响应的时刻 − 服务器整秒」反推出偏移量，多次采样后取中位数。

一个踩过的坑：如果采样窗口太短（比如临开火前只剩 2.5 秒），大概率抓不到整秒跳变，算出来的是垃圾值。所以对时必须在**开始等待时**做一次就够了——本机和服务器都是 NTP 同步的，等待期间不会自己漂移。临阵重测只会测得更差。

**3. 补取字段**

很多活动在开放前不返回表单字段（服务器直接拒绝）。工具会在开放前 5 秒再取一次，拿到 `field_name` / `field_key` 后按姓名、学号、学院匹配填值。字段名常带干扰后缀（`姓名#`、`学号%`）或干脆是算式（`12+1=`），匹配时会做归一化处理。

**4. 预热连接**

第一次 POST 到提交接口要走完整的 TLS 握手，实测能吃掉 1.2 秒。所以工具在等待期间先用 `HEAD` 请求把连接建好，开火时直接复用。

**5. 退避重试**

失败分两类，处理方式不同：

| 返回 | 含义 | 处理 |
|---|---|---|
| `invalid parameter`（60~150ms 内返回） | 没进业务逻辑，被网关拦了 | 重取字段，等一个限流窗口再发 |
| `请求过于频繁，请稍后重试` | 撞上频次限制 | 等约 2.9 秒再发 |
| `活动名额已满` | 真的没了 | 不重试 |

## 关于授权模块

`auth_core.py` 里带了一套简易的离线授权：机器码 + Ed25519 签名 + 到期时间，用于把程序分发给别人时限制使用。

**本仓库默认关闭授权校验**（`REQUIRE_LICENSE = False`），克隆下来直接能跑。

如果你想启用：

1. 自己生成一对 Ed25519 密钥，公钥填进 `auth_core.py` 的 `PUBKEY_B64`
2. 把 `REQUIRE_LICENSE` 改成 `True`
3. 私钥**只放在自己机器上**，用 `.gitignore` 挡住

> ⚠️ 私钥一旦提交到公开仓库，这套授权就彻底作废了——任何人都能签出永久、无限人数的授权。历史上这种事故非常多，务必在 `.gitignore` 里加 `private_key.txt`、`*.key`。
